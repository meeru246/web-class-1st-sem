HTML Basics Recap

1. HTML Structure

HTML is made up of elements.

        <opening-tag>Content</closing-tag>

2. HTML Element

            <h1>Hello World</h1>

Opening tag:<h1>

Content: Hello World

Closing tag:</h1>

3. Basic HTML Document

            <!DOCTYPE html>
            <html>
            <head>
            <title>My Page</title>
            <head>
            <body>
            <h1>Hello World</h1>
            <p>This is a paragraph.</p>
            </body>
            </html>
